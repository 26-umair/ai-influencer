AI INFLUENCER STUDIO — SETUP GUIDE
==================================

This project is a React + Vite prototype for creating and managing fictional virtual influencers for brand campaigns, social content, and visual storytelling.

REQUIREMENTS
------------
- Node.js 18 or newer
- npm
- A GitHub checkout of this repository

INSTALL
-------
npm install

START DEVELOPMENT SERVER
------------------------
npm run dev

Then open the local URL printed by Vite, usually:

http://localhost:5173

PRODUCTION BUILD
----------------
npm run build

PREVIEW PRODUCTION BUILD
------------------------
npm run preview

DEMO MODE
---------
Judges can review the product story without private API keys at:

/demo

RESPONSIBLE AI PAGE
-------------------
The responsible-use rules are available at:

/responsible-ai

GENERATION ACCOUNTS
-------------------
Full image generation outside demo mode requires connecting the supported external generation accounts through the app settings. Do not commit API keys or secrets to the repository.
