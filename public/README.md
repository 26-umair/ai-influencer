# Public demo assets

Demo media used by the hackathon prototype is grouped under `public/demo`:

- `public/demo/creators/` — sample fictional creator profiles and related media.
- `public/demo/gallery/` — landing/gallery/inspiration visuals.
- `public/demo/campaigns/` — product or campaign-specific sample assets.

These assets support the no-key judge demo and seeded local-first prototype data. Runtime paths intentionally stay public URL paths, for example `/demo/creators/camila/main.jpg`.
