## Demo GIF Flow

Target length: **8–15 seconds**.

Flow:

1. Start on `/demo` hero.
2. Scroll to sample persona and campaign output preview.
3. Jump to `/campaign-planner`.
4. Edit the brand name field.
5. Show generated plan update.
6. Click **Export demo packet**.

Recommended GIF filename:

```txt
ai-influencer-studio-flow.gif
```

## Notes

- Hide personal browser bookmarks if they reveal private data.
- Do not show account settings or API key fields in screenshots.
- Use PNG for screenshots and MP4 for the demo video. GIF is optional if submission supports it.
