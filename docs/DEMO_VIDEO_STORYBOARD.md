# Demo Video Storyboard

Target length: **90 seconds to 2 minutes**.

## Goal

Show that AI Influencer Studio is more than an avatar generator. The video should communicate a complete, safe campaign workflow:

1. Problem: small brands need affordable campaign visuals.
2. Demo mode: judges can review without private API keys.
3. Campaign planner: turn brand brief into strategy and post ideas.
4. Responsible AI: fictional-only, disclosure, consent, no minors.
5. Closing: submission is honest and build-ready.

## Recording Setup

- Browser: Chrome or Edge.
- Window: 1440×900 or 1920×1080.
- Zoom: 90–100%.
- Theme: use the default app look unless visual contrast is weak.
- Cursor movement: slow and deliberate.
- Do not show personal API keys, account tokens, private emails, Discord, or unrelated browser tabs.

## Shot List

### Shot 1 — Landing Page

Open the deployed app homepage.

Voiceover:

> AI Influencer Studio is a safe virtual creator platform for small brands and student founders. It helps users create fictional influencer identities, generate campaign-ready assets, and organize content from one workspace.

Action:

- Show hero section.
- Briefly hover over the main CTA.
- Click **Demo Mode** in nav.

### Shot 2 — Judge Demo Mode

Open `/demo`.

Voiceover:

> For judges, we created a no-key demo mode. It does not require Higgsfield, Claude, or private API keys. It shows the product story with sample fictional creator assets.

Action:

- Show badges: Judge Demo Mode, No API keys required, Fictional creator workflow.
- Scroll to sample persona.
- Point to safety guardrails.

### Shot 3 — Campaign Output Preview

Stay on `/demo` and scroll to campaign output preview.

Voiceover:

> The same fictional creator can become a reusable campaign asset pack: profile visuals, product moments, and branded content previews.

Action:

- Show image grid.
- Click **Open brand deals** or navigate back to nav.

### Shot 4 — Campaign Planner

Open `/campaign-planner`.

Voiceover:

> The campaign planner turns the project into a complete marketing workflow. The user enters brand, product, audience, tone, and channel, then gets positioning, content pillars, sample posts, and a safety checklist.

Action:

- Edit brand name or product name once so generated text updates.
- Scroll through campaign positioning, pillars, and sample posts.
- Click **Export demo packet**.

### Shot 5 — Responsible AI Page

Open `/responsible-ai`.

Voiceover:

> Responsible AI is built into the product story. The app is for fictional creators only, not real-person impersonation. It emphasizes consent, AI disclosure, 18+ characters, and human review before publishing.

Action:

- Show principles/checklist.
- Pause briefly on prohibited uses.

### Shot 6 — Closing

Return to `/demo` or the homepage.

Voiceover:

> This prototype is submission-ready for review as a safe virtual creator campaign platform. The repository includes build checks, clean documentation, demo mode, campaign planner, export packet, and responsible AI disclosure.

Action:

- End on homepage or demo hero.
