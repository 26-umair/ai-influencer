This checklist is the final operator view before submitting AI Influencer Studio to the hackathon portal.

- [x] README is clean and hackathon-focused.
- [x] Setup guide is repository-specific.
- [x] Legacy attribution, old setup material, and unrelated agent files are removed.
- [x] Demo assets are organized under `public/demo`.
- [x] GitHub Actions build check passes.
- [x] PR contains Phase 1 and Phase 2 improvements.

## Demo Walkthrough Order

Use this order during judging:

1. Homepage — explain project and problem.
2. `/demo` — no-key judge demo, sample persona, output preview.
3. `/campaign-planner` — campaign brief, generated plan, sample posts.
4. Export demo packet — show downloadable Markdown output.
5. `/responsible-ai` — safety, disclosure, consent, no minors, human review.
6. GitHub README/build check — prove project is clean and buildable.

## Honest Claims

Only claim what is currently true:

- The app is a React/Vite prototype.
- It has no-key demo mode.
- It has a campaign planner and demo packet export.
- It has visible responsible AI rules.
- It has GitHub Actions build checks.
- It has Vercel-ready configuration.
- Full generation outside demo mode requires connecting the supported external generation accounts.
- Alibaba Cloud, Qoder, or Qwen should not be claimed as implemented unless actually used or integrated later.
